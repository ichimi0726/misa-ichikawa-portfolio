## 🖼️ 写真をご自身の写真に差し替える方法

現在は雰囲気をつかみやすいよう、おしゃれなイメージ写真を仮配置（プレースホルダー）しています。
ご自身の写真に差し替える手順はとても簡単です！

### 方法 1: ローカルの写真ファイルを指定する（一番おすすめ）
1. このフォルダの中に **`images`** という新しいフォルダを作ります。
2. その中に、使いたい写真（例: `my-photo.jpg`, `lacrosse.jpg`, `friends.jpg` など）を保存します。
3. `index.html` をメモ帳やエディタで開き、`src="..."` の部分をご自身のファイル名に書き換えます：
   ```html
   <!-- 例: メインのポラロイド写真 -->
   <img src="images/my-photo.jpg" alt="Misa" class="clickable-photo" />
   ```

### 方法 2: Googleドライブや画像URLを使う
Web上の画像リンク（URL）をそのまま `src="https://..."` に貼り付けても表示されます。
